# IMD SYNOP Encoder (static web build)

Open `index.html` locally or upload this entire folder to any static web host. The page is self-contained and does not need a server-side Python process or external libraries. It supports manual UTC date/time, table-based RH/dew point with vapour pressure derived from dew point, WMO 4677/4561 group 7 dropdowns, separate rain and weather cards, 03 UTC group 555 rainfall, separate WMO N/Nh/h and CL/CM/CH cloud selectors (slash means unavailable; h defaults to 9), a synchronized manual 8NhCLCMCH field, past-weather-first then present-weather selectors, and wind direction as degrees, WMO dd codes, or a 16-point compass selection. Hosting provider/domain can be selected later.

Cloud group 8 accepts a fixed leading 8 followed by four editable characters (NhCLCMCH); typing those characters updates the dropdowns, and dropdown selections update the manual field. The weather controls appear together in W1, W2, ww order. Cloud code tables: WMO 2700 (N/Nh), 1600 (h), 0513 (CL), 0515 (CM), and 0509 (CH).
